# Baton archive — closed handoffs, kept verbatim

`baton.md` is the live {{PLANNER}} ↔ {{IMPLEMENTER}} channel. When {{PLANNER}} prunes it
on pickup, closed blocks move **here** instead of being deleted (`WORKFLOW.md` §2.4).
Everything below is **verbatim**, newest at the top. Nothing is summarized or rewritten
on the way in.

## How to use it

- ⛔ **Do not read this file at session start.** It is not on the checklist. It is a grep
  target for *"why did we decide X?"* and *"which PR closed Y?"*.
- **The durable record is elsewhere and wins.** Live vs designed →
  `implementation-status.md`; pending → `backlog.md`; the designs → `engineering/` and
  `product/`. If this archive disagrees with any of those, **they are right and this is
  stale** — these are point-in-time snapshots of what a terminal believed mid-cycle,
  including beliefs later corrected.
- **Append-only, and only {{PLANNER}} appends**, on pickup, after reading.
